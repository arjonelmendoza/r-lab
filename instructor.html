How tests work

Write one test per line: points | description | R expression. A test passes when the expression is TRUE.

Inside a test you can use the student's variables, .ref (a fresh copy of the setup data, so students can't tamper with it), and .output (everything their code printed).

2 | total_sales is correct | abs(total_sales - sum(.ref$sales$amount)) < 0.01
1 | prints the total | grepl("Total", .output)
2 | uses group_by | grepl("group_by", .code)

Unique data per student: the setup code gets a .seed unique to each student. Start setup with set.seed(.seed) and generate data randomly, so every student gets different numbers and answers can't be shared. Tests compare against .ref, so grading still works.

Sample tests are visible to students (they can check them). Hidden tests and the reference solution are stored privately and only run here when you grade.

Updates live. Click a student for their timeline, code replay and details.

Grading runs the R code in this browser. Keep this tab open until it finishes. Each student is graded with their own data seed.
